# सारथी AI Android App

यह Android Studio project है। इसमें mobile-first Sarathi AI interface, AI Chat, Voice, Study, Notes, Reminder और Calculator शामिल हैं।

## Build
Android Studio में यह folder खोलें और Gradle sync करके Run/Build APK करें।

ध्यान दें: इस environment में Android SDK/Gradle build tools उपलब्ध नहीं मिले, इसलिए यहाँ से compiled APK बनाना संभव नहीं हुआ।
